# v0가 실패한 이유

## 어떻게 만들어졌나
- 만들게 된 계기는 실험과목 결과 분석의 불편함.
  모두가 다른 AI모델과 프롬프트를 사용했기 때문에,
  결과의 오차와 분석이 모두 다르고 신뢰도가 떨어짐.
- 이에 따라 기준점이 되는 + 시간을 단축시킬 수 있는    
  프로그램을 만들고 싶었음.  
- But, 방학 때, AI에게 프롬프트만 입력해서 만들었음.
  (바이브 코딩을 활용) 
  내가 이해한 코드 비율은 0%에 가까움.


## 겉보기 문제
- 실제 써봤을 때 에러가 나면 고칠 수가 없었고(AI에게 
  오류메세지와 상태를 쓰고 다시 전체 코드를 복사 붙여넣기 하는 작업을 반복해야했음) 
- 실험에서 발생하는 변수와 돌발상황은 물론이거니와 
  AI가 만든 코드에 입력된 형식으로만 입력을 해야된다는 불편감이 발생.(변수명 하나만 틀려도 멈춰버렸음)
- 실제 실험 분석에서도 큰 도움을 얻지못했고, 그저
  계산의 역할만을 반복할 뿐이었음.
  (신뢰도 문제도 해결되지않음)
- 무엇보다 내가 아닌 AI가 1부터 100까지 만들었기 
  때문에 프로젝트로 활용하기 어려웠고, 겉보기에만 좋은 결과물이 됨.    

## 구조 문제
1. 2,140줄 중 핵심 분석 코드 약 120줄 
   — 실험 문제를 푸는 부분이 작고 포장(UI/UX)이 큼
2. 불확도 입력이 없음 → 이론값과 일치하는지 판정 불가
   (위와 마찬가지로 신뢰도 문제 해결X)
3. CSV 입출력 없음 → 다른 사람과 데이터 공유 불가
   (또한, 실험 데이터를 직접 타이핑하거나 전처리를 일일히 해야된다는 불편감 발생)

## v1(새 프로젝트)에서 다르게 할 것
- 웹 앱 개발을 멈추고, Jupyter Notebook에서 내 손으로 
  직접 Pandas를 써서 데이터를 깎고 계산할 것.
- 코드를 이해하고 질문을 받았을 때 대답할 수 있도록 함.
- 교수님 혹은 현직자분들에게 자문을 받을만한 결과물 도출
