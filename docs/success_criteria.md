# 프로젝트 성공 기준 (15개 테스트)

이해했다는 "느낌"이 아니라, "AI 없이 시간 제한 안에 할 수 있다"를 기준으로 평가(객관적인 지표 필요).

## 1층: 코딩 능력 (AI검색만 허용)
### 테스트 기준
----------------------------------------------------
1. 처음 보는 세로형 CSV → 그룹별 평균·표준편차·개수 표 _20분
2. 위 데이터에 직선 피팅 → 기울기·절편·기울기 불확도 → 물리량 환산_30분
3. 잔차를 독립변수에 대해 플롯하고 png 저장_15분
4. `legacy/app_v0.py`의 `compute_stats` 함수를 열어 한 줄씩 무슨 일인지 말하기_70% 이상
5. 내 `src/physlab/` 함수 중 하나를 골라 "왜 이렇게 짰나" 설명, 요구사항 바꾸면 어디 고칠지 짚기(막힘 없이)
6. 내 코드에 에러를 하나 심어놓고 원인 찾아 고치기_30분

## 2층: 물리·통계 (코딩 배운 사람과 구별되는 무기)
### 테스트 기준
----------------------------------------------------
7. "이 실험 결과가 이론과 일치하나?"에 오차율 %가 아니라 불확도 대비 편차로 답하기_항상
8. 환산 χ²(카이제곱)가 3.2 / 1.0 / 0.2일 때 각각 무슨 뜻인지 말하기
9. 잔차 플롯을 보고 "랜덤이다 / 체계 오차가 있다"를 판단하고, 어떤 종류인지 가설 세우기_실제 사례 1개 이상(이 부분이 자소서 작성의 핵심이 될 것)
10. 왜 v0의 1/5/10% 등급이 무의미한지 설명

## 3층: 작업 방식 (현업에서 통하는 습관)
### 테스트 기준
----------------------------------------------------
11. 커밋 이력을 보면 점진적 변화가 보이고, 메시지만 읽어도 뭘 했는지 알 수 있다.
12. `tests/`에 정답 아는 가짜 데이터로 함수가 맞는지 확인하는 테스트가 있고 통과한다.
13. 원본 CSV를 한 번도 손으로 수정하지 않았다.
14. 조원 한 명이 README만 보고 내 스크립트를 돌려 같은 숫자를 얻는다.
15. 교수님/박사님께 2~3쪽 요약을 들고 가서 한계와 질문을 내가 말할 수 있다(자문 1회 실행)

- **학기 말 최종 판정:** 15개를 혼자 시험 보듯 실행하여 12개 이상 통과 시 "성장했다"고 자신 있게 자소서에 작성 가능.
- **실패 항목 기록:** 못 한 것도 기록할 것.

- **중간 체크:** 
  - 한 달 뒤: 1, 4번 체크
  - 광학 실험 직후: 1~3, 7번 체크
